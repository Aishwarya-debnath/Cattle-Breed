# Cattle-Breed
Transfer learning-based cow breed classification framework using deep learning models, optimized for accuracy and lightweight deployment in rural and resource-constrained environments.
## Project Overview
In developing countries, livestock plays a crucial role in public health, food security, and rural economic stability. However, accurate breed identification remains a challenge for small-scale farmers, affecting nutrition planning, disease management, and sustainable livestock development.
This project proposes a deep learning-based cow breed classification framework using transfer learning. The system is trained on an enhanced dataset of 6,040 images covering five distinct cattle breeds.
We evaluate and compare four architectures: LaVin-DiT, CoAtNet, EfficientNetV2, and DAMambaNet. Among these, EfficientNetV2 achieved the highest classification accuracy of 95.6%, while DAMambaNet demonstrated superior efficiency in terms of model size (6.18 MB) and inference speed (0.5 ms), making it suitable for mobile and edge deployment in rural environments.
The proposed framework supports One Health objectives by enabling accurate breed identification to improve breeding decisions, vaccination planning, and nutritional management. Field validation remains an ongoing step to ensure real-world applicability and robustness.
